# 会话织匣：范围与验收

## 改动范围

- 新增 `src/components/chat/SessionManager.vue`、`SessionIcon.vue`、`session-manager.css`：按需打开的会话卡片浮层，样式 scoped，不新增侧边栏。
- 新增 `src/composables/useChatSessions.js`：浏览器本地会话存储、草稿、标题、置顶与旧存档迁移。
- `ChatPanel.vue` 仅接入入口、独立草稿、当前对话清空确认；欢迎卡片保持不变。
- `useCultureChat.js` 仅接入分会话保存/恢复，以及切换、删除、离页时的回复隔离。
- `src/api/qwen.js` 仅增加可选的请求取消信号，原调用方式保持兼容。
- `package.json` 只增加 `test:sessions` 命令。不增加运行时依赖。
- 不改其他页面、全局样式、Live2D 模型、后端和未跟踪的 `sample/`。

## 数据约定

- 新键：`zhichuan-culture-sessions-v1`，仅当前浏览器保存，不是账号云端同步；同一浏览器的不同登录账号也共用这份本地存档。
- 旧键：`zhichuan-culture-chat`。首次读取时迁移文字、图片与上下文，新存档写入成功后才移除旧键。
- 每段保留最近 50 条消息，AI 上下文继续沿用最近 6 轮完整对话。
- 标题默认取首次提问，手动重命名后不再自动覆盖；切换不会改变最近更新时间。
- 删除最后一个会话会补建空会话，清空仅影响当前会话。
- 切换时终止当前回复，保留已经显示的文字；未完成的图片请求结果不写入其他会话。
- 恢复使用文本节点和重新创建的图片，不执行存档 HTML；恢复的图片仍可点击预览。
- 存储不可用/已满时退回内存状态并显示警告，不假装保存成功。

## 浏览器验收清单

进入 `/culture`，点击工具栏「会话织匣」。

- [ ] 默认只显示小入口，聊天区域无侧栏；打开后背景模糊、暖金轨道轻旋转、卡片错峰显现。
- [ ] 新建空对话，欢迎卡片保留；旧消息与未发送草稿切换后可恢复。
- [ ] 搜索标题/消息正文；置顶置前；置顶筛选和无结果状态正常。
- [ ] 重命名 Enter 保存、空白名称不能保存、Esc 取消编辑但不关闭织匣。
- [ ] 删除有二次确认；取消不修改记录；删除最后一个会话仍可继续聊天。
- [ ] 清空当前对话有确认，其他会话不受影响。
- [ ] 刷新和离开再返回可恢复当前会话、消息及草稿。
- [ ] 回复请求等待中或打字中切换会话：旧回复、旧错误提示不会进入新会话，也不会解锁新会话正在发送的输入。
- [ ] 图片生成期间切换：旧图片和额度错误不进入新会话。
- [ ] 旧存档迁移保留换行与图片，忽略临时问候/思考气泡，不执行事件属性。
- [ ] 点击遮罩、关闭按钮、Esc 可收起；Tab 保持在对话框内，关闭后焦点回到入口。
- [ ] 390px 手机宽度单列且可滚动，横屏低高度仍可访问所有控件。
- [ ] 系统开启「减少动态效果」后不播放卡片旋转/入场动画。

开发时已使用隔离的 Chromium 浏览器验证以上核心交互、移动端、异步隔离与迁移；AI/TTS 使用拦截响应，不消耗真实服务额度。浏览器测试工具安装于临时目录，不加入项目依赖。
